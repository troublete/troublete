## Index

### Go

- [go-plan](https://github.com/troublete/go-plan)
  A module for creating an order of elements, based on the interdependence of them; e.g. creating execution orders of
  interdependent tasks.
- [go-annotation](https://github.com/troublete/go-annotation)
  A module that allows to interpret annotations from commented go code, to allow for meta programming or additional
  inline configuration; e.g. rapid-prototyping configuration for code generation based on annotated code.
- [go-radix](https://github.com/troublete/go-radix)
  A module that contains a radix tree implementation which allows for wildcard definitions and value capturing along the
  way; might be useful for routing applications e.g. web-server
- [go-lobby](https://github.com/troublete/go-lobby)
  A module that allows to create shared in-memory data-exchange sessions; this allows the communication between multiple
  clients without the need for a database e.g. chat-server, ...
- [go-sst](https://github.com/troublete/go-sst)
  A module that allows linear flow analysis of hierarchical entities with
  validation, similarily to solid-state implementation but for state
  correctness
